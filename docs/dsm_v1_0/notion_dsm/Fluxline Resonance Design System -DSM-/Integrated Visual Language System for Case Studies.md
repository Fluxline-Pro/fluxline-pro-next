# Integrated Visual Language System for Case Studies & Portfolio

## 1. Case Studies (Deep Narrative)

### Visual Anchors

- **Glyphs from DSM**
    - Use *Curriculum Phase Glyphs* (Initiation Gate, Descent Chamber, Integration Seal, Expansion Glyph) to mark each section:
        - **Challenge** → Initiation Gate
        - **Approach** → Descent Chamber
        - **Outcome** → Integration Seal
        - **Fluxline Embodiment** → Expansion Glyph
    - Emotional Threshold Glyphs (Ache, Breakthrough, Sovereignty) can tag sidebars or reflections.
- **Color Gradients**
    - Apply **Fluxline Ascension** (Blue → Gold) for section dividers, symbolizing movement from depth to illumination.
    - Use **Glyph Gate Fade** (Gold → Dark Blue) for transitions between narrative phases.
- **Iconography**
    - Fluent UI icons for clarity (Lightbulb = insight, ShieldCheckmark = ethical guardrails).
    - Custom glyphs (Portal, Spiral, Wave) as ritual markers for transformation points.

### Layout Guidance

- **Section Headers**: Use *Book Covers & Section Headings* template (gradient background, diagonal line) to mark each case study gate.
- **Body Text**: Pair narrative with glyph watermarks (e.g., Shadow Glyph in footer for challenge sections).
- **Reflection Notes**: Use *Mini Card Template* for closing insights—small, symbolic cards with glyph overlays.

## 2. Portfolio Pieces (Concise Showcases)

### Visual Anchors

- **Glyphs**
    - Use *Training Cycle Glyphs* (Activation, Recovery, Transition) to tag coding/design phases.
    - Archetype Glyphs (Architect, Flamebearer, Witness) can denote your role in each project.
- **Color System**
    - Accent with **Mythic Gold** for highlights and CTA buttons.
    - Use **Somatic Drift** (Rose → White) for emotional or design-focused pieces.
    - Apply **Fluxline Pulse** (Teal → Gold) for interactive hover states or modular nodes.
- **Iconography**
    - Use icons as semantic cues:
        - Globe = global resonance for design projects.
        - BranchFork = modular divergence for coding projects.
        - HeartPulse = vitality for emotionally resonant work.

### Layout Guidance

- **Snapshot Section**: Use *Flyer / One-Pager Template* (landscape) for quick overviews.
- **Visual Showcase**: Replace screenshots with *Curriculum Map / Phase Diagram Template* or abstract glyph overlays.
- **Outcome Snapshot**: Use *Checklist / Tracker Template* for metrics and results.
- **Fluxline Resonance**: Anchor with *Duality Page Template* (e.g., “Employer Past” vs. “Fluxline Present”).

## 3. Unified Design System Rules

- **Sizing & Scaling**: Icons/glyphs scale by powers of 4 (16px for navigation, 48px for ritual zones).
- **Color Harmony**: Stick to Fluxline’s palette (Steel Blue, Mythic Gold, Somatic Rose, Fluxline Teal).
- **Typography**: Once your Typography DSM finishes processing, align headers/subheaders with Playfair Display (mythic tone) and Inter (technical clarity).
- **Consistency**: Every case study and portfolio piece should carry at least one glyph, one gradient, and one semantic icon—so the constellation feels alive.
