# 12. Cards

| Property | Value / Ritual |
| --- | --- |
| Border Radius | `12px` — soft enough to feel inviting, modular enough to stack |
| Padding | `16px` inside, `24px` outside margin |
| Elevation | Default: `elevation16`; Hover: `elevation64` |
| Background | `colorNeutralBackground1` with optional spiral watermark (5% opacity) |
| Border | `1px solid` with `colorNeutralStroke1` or mythic accent |
| Animation | Fade-in on load, scale on hover |
