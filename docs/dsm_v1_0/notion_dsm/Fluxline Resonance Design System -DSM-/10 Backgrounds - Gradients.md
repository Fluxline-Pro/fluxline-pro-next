# 10. Backgrounds & Gradients

| Element | Background Style | Notes |
| --- | --- | --- |
| Page | `colorNeutralBackground3` with optional spiral watermark | Breath and spaciousness |
| Cards | Solid with optional radial gradient (`Mythic Gold` to transparent) | Symbolic glow |
| Icons | Linear gradient (`Fluxline Teal` → `Somatic Rose`) on hover | Emotional pulse |
| Modals | Semi-transparent overlay (`rgba(46,46,58,0.8)`) | Depth and focus |

> Gradients should be subtle—used as emotional cues, not visual noise.
>
