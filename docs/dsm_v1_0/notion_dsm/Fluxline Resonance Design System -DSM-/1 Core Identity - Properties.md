# 1. Core Identity & Properties

### **Core Identity**

- **System Name**: Fluxline Resonance DSM
- **Tagline**: “Designing for Mythic Self-Authorship”
- **Purpose**: To unify visual, emotional, and modular design principles across all Fluxline products and rituals.

### Core Properties

| Property Name | Type | Description |
| --- | --- | --- |
| `Component Name` | Title | Clear, modular naming (e.g., `Button/Primary`) |
| `Category` | Select | UI Element, Layout, Typography, Motion, Print |
| `Emotional Tag` | Multi-select | Tags like `#invitation`, `#authority`, `#presence`, `#fluidity` |
| `Behavioral Cue` | Text | What behavior this component invites (e.g., “nudges action gently”) |
| `Usage Context` | Multi-select | Web, Print, Motion, Relational, Brand Ritual |
| `Visual Reference` | URL or File | Link to XD artboard or embedded image |
| `Synced Block` | Notion block | Embed synced spec from Reference Hub |
| `Accessibility Notes` | Text | Contrast, legibility, motion sensitivity, etc. |
| `Relational Tone` | Text | Emotional voice this component carries (e.g., “warm invitation,” “firm boundary”) |
| `Design Principles` | Multi-select | Stewardship, Modularity, Resonance, Integrity, Stillness |
| `Last Updated` | Date | For changelog tracking |
| `Status` | Select | Draft, In Review, Finalized, Deprecated |
