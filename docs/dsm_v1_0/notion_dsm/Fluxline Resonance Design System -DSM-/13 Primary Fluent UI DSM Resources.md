# 13. Primary Fluent UI DSM Resources

### 🧠 **Fluent UI v9 Design System (Fluent 2)**

- 🚀 [Fluent 2 Developer Portal](https://fluent2.microsoft.design/get-started/develop)
Your go-to for getting started with Fluent UI React v9, including theming, component usage, and migration guides.
- 📦 [Fluent UI React v9 Overview](https://deepwiki.com/microsoft/fluentui/3.2-react-v9-%28@fluentuireact-components%29)
Architectural breakdown of the v9 component model, Griffel integration, and token-based theming.
- 🧱 [Fluent UI GitHub Repo](https://github.com/microsoft/fluentui)
Source code, issues, RFCs, and community discussions around Fluent UI’s evolution.

### 🧬 **Griffel (CSS-in-JS Engine for Fluent UI v9)**

- 📘 [Griffel Official Documentation](https://griffel.js.org/)
Covers setup, API (`makeStyles`, `mergeClasses`, `shorthands`), SSR support, and performance optimization.
- 🎥 [Fluent UI React Insights: Griffel](https://learn.microsoft.com/en-us/shows/fluent-ui-insights/fluent-ui-insights-griffel)
A behind-the-scenes video from the Fluent UI team explaining Griffel’s architecture and atomic CSS strategy.
- 📚 [Griffel Style Handbook on GitHub](https://github.com/microsoft/fluentui/blob/master/docs/react-v9/contributing/rfcs/react-components/styles-handbook.md)
Deep dive into Griffel’s best practices, limitations, and how it integrates with Fluent UI React v9.
